## Description

QDegradeBench is a research dataset for evaluating large language model behavior under progressive loss of task-critical information. It contains 32 Chinese base tasks, each represented by a matched four-level information-degradation chain, yielding 128 prompts. Four API endpoints produced 512 responses. Every response has a final human-confirmed behavior label, and a stratified sample of 128 responses was independently reviewed by a second human annotator. The package includes prompt-level answerability metadata, complete model responses, final behavior labels, double-review data, an annotation codebook, experimental metadata, and a standard-library Python script that reproduces the reported ARR, UAR, IDU, critical-information failure onset, agreement, and Cohen's kappa results. AI-generated preliminary labels, reviewer identities, private notes, credentials, and service configuration are excluded.
