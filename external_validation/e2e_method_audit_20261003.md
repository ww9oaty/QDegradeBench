# 外部验证方法核验（2026-10-03）

## 发现与处理
1. CFO必须以适当的L1回答为前提。已加入排除计数 excluded_L1_inappropriate 和合格轨迹数 CFO_eligible。
2. 脚本原先会在各等级标签不齐时计算IDU。现有缺失标签或不完整轨迹时IDU为null；等级统计仍为已标注子集，analysis_status标记 incomplete。
3. 重复轨迹等级、非法标签和非法充分性类别现在报错；全部空标签的轨迹不再消失。单一恒定标签的kappa不可定义，返回null。
4. 原始提示在L0/L1/L2各有24个不同文本，L3只有1个不同文本，重复24次。共96个提示记录，但仅73个不同提示文本。L3不能作为24个不同独立题目；重复请求可保留为同一提示的多次输出。
5. L3要求写餐厅描述却未明确禁止创作，也未指定真实餐厅。虚构描述可能符合另一种合理任务理解。不能仅凭当前初标宣称模型在明确事实任务中必然幻觉。
6. L2只复述六个已知字段的回答：按现有CA定义可覆盖“可完成部分”，但没有完成八字段要求，也没有承认不足，和PA边界有张力。必须额外记录字段覆盖、是否明确承认缺失以及是否添加无依据断言，不能直接把CA等同完全遵从任务。
7. 初标曾忽略部分非字段事实性修饰（如优秀服务、具体菜单、氛围）。人工支持性检查须覆盖这些断言，不能仅比较八字段。现有AI初标只能作待审建议。
